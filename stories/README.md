# Your stories

Put each story in its own `.txt` file in this folder. The agent reads them word for word,
oldest file name first (so `01-...`, `02-...` keeps them in order).

- **First line:** the post title. It's shown on the card at the start and read aloud first.
- **Everything below it:** the story.

About 150 words is roughly one minute of narration. Shorts can be up to 3 minutes.
After a story is posted, it moves to `stories/used/` so it's never posted twice.
