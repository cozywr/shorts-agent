# Privacy policy

Last updated: November 7, 2026

shorts-agent is a private tool used only by the owner of the StickFigure Ideas YouTube channel. It is not offered to the public.

**What it accesses.** With the owner's permission, it uses the YouTube Data API scope `youtube.upload` only to upload the channel's own videos (with their title, description and publish time) to the owner's own channel.

**What it does not do.** It does not read, collect, store, sell or share any personal data, viewer data or data from other Google services. The access token is kept only as an encrypted secret in the owner's GitHub account and is used only to upload videos.

**Removing access.** The owner can remove access at any time at https://myaccount.google.com/permissions.
